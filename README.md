# Customer Segmentation Using K-Means Clustering

## Project Overview

This project uses unsupervised machine learning to segment customers into groups based on their purchasing behavior and other relevant features. K-Means Clustering identifies customer groups to help businesses understand customer patterns and improve marketing strategies.

## Objectives

* Analyze customer data.
* Perform exploratory data analysis.
* Preprocess and scale numerical features.
* Apply K-Means Clustering.
* Determine the optimal number of clusters using the Elbow Method and Silhouette Score.
* Visualize customer segments.
* Interpret the characteristics of each cluster.
